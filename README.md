# NoMoreBing

A Microsoft Edge extension that keeps Edge from silently switching your address bar search engine back to Bing.

## How it works

Edge has no extension API for reading or changing the default search engine. The one supported route is `chrome_settings_overrides`, which lets an extension provide the default search engine while it is enabled. NoMoreBing uses it like this:

1. The manifest makes `https://nomorebing.invalid/search?q={searchTerms}` the default search engine. `.invalid` is a reserved domain that never resolves.
2. When you pick an engine on the options page, a `declarativeNetRequest` rule redirects that placeholder to the engine you chose.
3. The redirect happens before the request leaves the browser, so your query only goes to the engine you picked. If the rule is ever missing, the request goes nowhere instead of falling back to another engine.

While the extension is enabled, Edge's search settings show the search engine as controlled by NoMoreBing. Edge's own reset only clears the user-level setting underneath, so the address bar keeps using NoMoreBing. To hand control back to Edge, turn off or remove the extension.

The only permissions are `declarativeNetRequest`, `storage`, and host access to `nomorebing.invalid`. The extension does not read the pages you visit.

## Search engines

- Google
- DuckDuckGo
- Baidu
- Brave Search
- Startpage
- Ecosia
- Custom: any `http(s)` URL with `%s` where the search terms go

Your choice is saved in `storage.sync`, so it follows your Edge profile.

## Address bar suggestions

Suggestions can't follow the engine you pick at runtime. Edge fetches them from the browser process, where extensions can't intercept requests, so the suggestion URL has to be written into the manifest and is fixed once the extension is installed.

Instead, there is one package per suggestion provider: `google`, `duckduckgo`, `baidu`, `brave`, `startpage`, `ecosia`, and `none` (no suggestions). Until you pick a search engine, the extension searches with the same provider its suggestions come from. The options page shows which provider your package uses. To change it, install a different package.

To turn suggestions off without reinstalling, switch off "Show me search and site suggestions using my typed characters" in `edge://settings/search`.

## Scope

NoMoreBing only covers the address bar default search engine. It does not change the search box on the new tab page, sidebar search, Copilot, or links that Windows opens in Edge.

## Install from source

1. Clone this repository.
2. Build the package for the suggestion provider you want, for example `npm run build -- duckduckgo`. To get Google suggestions you can skip this step and load the repository folder itself.
3. Open `edge://extensions` and turn on **Developer mode**.
4. Click **Load unpacked** and select `dist/<provider>/`.
5. Keep the change when Edge asks about the new search settings, then pick an engine on the options page that opens.

## Development

The repository folder is itself a loadable extension, using Google suggestions. The extension is plain JavaScript modules loaded straight from `src/`, with no bundling.

```
manifest.json          MV3 manifest, including the search provider override
_locales/              English and Simplified Chinese strings
src/engines.js         Engine presets and redirect rule builder (no browser APIs)
src/settings.js        Reads and writes the engine choice in storage.sync
src/background.js      Service worker that keeps the redirect rule in sync
src/options/           Options page
icons/                 Extension icons, generated by scripts/make-icons.js
scripts/build.js       Builds one package per suggestion provider into dist/
scripts/dse-reset.js   Simulates and inspects Edge's search engine reset
test/                  Unit tests
```

With Node.js 22 or later:

```
npm test                                  # unit tests
npm run build -- <provider|none|all>      # dist/<provider>/ and dist/nomorebing-<version>-<provider>.zip
npm run icons                             # regenerate icons/
npm run dse-reset -- check  <user-data-dir>
npm run dse-reset -- tamper <user-data-dir>
```

Builds are reproducible: the zip writer uses fixed timestamps.

`dse-reset tamper` edits the stored default search engine in a throwaway Edge profile so that Edge treats it as tampered and resets it on the next launch. It refuses to touch your real Edge profile or a profile that Edge is currently using. `check` is read-only and prints the stored engine plus Chromium's reset markers (`prefs.preference_reset_time`, `prefs.tracked_preferences_reset`).
